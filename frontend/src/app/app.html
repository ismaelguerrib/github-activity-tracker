LE CONCEPT

Votre activité GitHub, sans le terminal.

GitHub Activity interroge votre session GitHub CLI locale pour reconstruire,
jour par jour, ce qu’un membre d’une organisation a réellement produit.

01

Vous configurez l’analyse

Organisation, utilisateur, mois. Aucun token à saisir : l’outil réutilise la connexion gh déjà présente sur votre machine.

02

L’outil collecte l’activité

Il parcourt les dépôts et la recherche GitHub pour retrouver commits, pull requests, issues, reviews et commentaires, puis déduplique le tout.

03

Les jours actifs apparaissent

Le rapport affiche le nombre de jours actifs, le total de contributions et le détail au jour le jour, directement dans cette page.

04

Vous exportez

Téléchargez le même rapport en CSV pour vos tableaux ou en PDF prêt à partager. Tout reste sur votre poste.
